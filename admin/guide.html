Как пользоваться админкой

Админка находится по адресу ваш-сайт/admin. Всё, что вы там меняете, сохраняется в GitHub, и сайт обновляется сам примерно через минуту.

01Вход

  1. Откройте ваш-сайт/admin.
  2. Нажмите «Войти с помощью токена доступа» и вставьте токен GitHub (начинается с github_pat_).
  3. Браузер запомнит вход. На новом устройстве токен понадобится снова.
Каждому человеку в команде лучше выпустить свой токен: GitHub → Settings → Developer settings → Fine-grained tokens. Доступ только к репозиторию annonce-site, Contents: Read and write. Человека нужно сначала добавить в репозиторий: Settings → Collaborators.

02Что где лежит

КейсыКаждый кейс — отдельная страница /cases/адрес/. Карточки кейсов на главной собираются отсюда автоматически.
Статьи блогаКаждая статья — отдельная страница /blog/адрес/.
Блоки главной страницыТексты всех блоков главной, порядок блоков, квиз, контакты, SEO.

03Изменить текст блока

  1. Откройте Блоки главной страницы и выберите блок, например «Услуги».
  2. У каждого текста два поля: RU и EN. Если EN пустое, на английской версии будет пусто — заполняйте оба.
  3. Элементы списка (услуги, тарифы, отзывы, вопросы квиза) можно добавлять кнопкой «Добавить», удалять через меню у элемента и перетаскивать за ручку слева, чтобы поменять порядок.
  4. Нажмите «Сохранить».

Галочка «Показывать блок» прячет блок с сайта, ничего не удаляя.

04Порядок блоков

Блоки главной страницы → Порядок блоков. Перетащите блоки в нужном порядке сверху вниз. Если удалить блок из списка, он пропадёт с сайта; вернуть можно кнопкой «Добавить». Первый экран и подвал всегда стоят на своих местах.

05Новый кейс

  1. Кейсы → Новый кейс.
  2. Адрес страницы — латиницей через дефис, например dental-clinic-meta. Потом его лучше не менять: старые ссылки перестанут работать.
  3. Дата — по ней кейсы сортируются, новые идут первыми.
  4. Заполните метку, заголовок, краткое описание (оно на карточке на главной), обложку, характеристики и результаты — большие цифры вверху страницы.
  5. Текст страницы — обычный редактор: заголовки, списки, жирный, ссылки, картинки. Заголовки второго уровня сами попадают в оглавление слева.
  6. Галочка «Черновик» — кейс сохранится, но на сайте его не будет.

06Новая статья

Так же, как кейс: Статьи блога → Новая статья. Время чтения считается само.

07Картинки

Обложка кейса / статьи1920×1080 или больше, горизонтальная
Карточка на главнойта же обложка, обрезается по центру
Логотипы клиентовPNG или SVG с прозрачным фоном; на сайте становятся монохромными
Фото командыквадрат, от 800×800
Картинка для соцсетейровно 1200×630

Перед загрузкой сжимайте фото, например на squoosh.app: до 300–400 КБ на картинку. Сайт будет грузиться быстрее.

08Предпросмотр

Справа от полей показывается сайт и прокручивается к блоку, который вы редактируете. Изменения видны сразу, ещё до сохранения. Если панели не видно, нажмите иконку предпросмотра в верхней панели редактора.

09Публикация

После «Сохранить» сайт пересобирается примерно за минуту. Если изменений не видно, обновите страницу без кэша: Cmd+Shift+R (Mac) или Ctrl+F5 (Windows).

10Заявки в Telegram

Заявки из квиза приходят в два места: в Netlify (раздел Forms) и в Telegram, если подключить бота. Подключение делается один раз:

  1. В Telegram откройте @BotFather → /newbot → придумайте имя. Он пришлёт токен.
  2. Напишите своему боту любое сообщение. Если заявки должны приходить в группу, добавьте бота в группу и напишите там.
  3. Откройте в браузере https://api.telegram.org/botТОКЕН/getUpdates и найдите "chat":{"id":…} — это ID чата. У групп он начинается с минуса.
  4. Netlify → ваш сайт → Site configuration → Environment variables → Add a variable: TELEGRAM_BOT_TOKEN = токен, TELEGRAM_CHAT_ID = ID чата. Несколько чатов — через запятую.
  5. Deploys → Trigger deploy → Deploy site.
  6. Отправьте тестовую заявку через квиз на сайте.
Письма о заявках на почту: Netlify → Forms → Form notifications → Add notification → Email.

11SEO

Блоки главной страницы → SEO и превью для соцсетей: заголовок и описание сайта для Google и картинка, которая показывается, когда ссылку присылают в Telegram, WhatsApp или Facebook. Для кейсов и статей заголовок, описание и картинка берутся из самих кейсов. Карта сайта /sitemap.xml обновляется сама.

Когда подключите домен, добавьте сайт в Google Search Console и отправьте туда адрес карты сайта.

12Если что-то сломалось

Каждое сохранение — это отдельная запись в истории GitHub. Откройте репозиторий → Commits, найдите последнюю рабочую версию и восстановите файл. Или в Netlify: Deploys → выберите прошлую версию → Publish deploy, и сайт откатится за секунду.
